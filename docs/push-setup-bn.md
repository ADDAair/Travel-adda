# ফোনে নোটিফিকেশন (পুশ) চালু করার নিয়ম

অ্যাপের কাজ শেষ। ফোনে নোটিফিকেশন পৌঁছাতে Google-এর **Firebase** লাগে (সব অ্যান্ড্রয়েড অ্যাপের জন্যই লাগে, এটা বিনামূল্যে)। এই কাজগুলো ল্যাপটপে একবার করতে হবে।

**নিরাপত্তা:** ধাপ ৪-এর "private key" ফাইলটা গোপন। এটা কাউকে চ্যাটে, ইমেইলে বা WhatsApp-এ পাঠাবেন না, এমনকি আমাকেও না। শুধু expo.dev-এ আপলোড করবেন, তারপর ল্যাপটপ থেকে মুছে ফেলবেন।

## ১. ডেটাবেস (২ মিনিট)
1. Supabase → **SQL Editor** → **New query**।
2. `travel-adda-011.sql` Notepad-এ খুলে পুরোটা কপি করে পেস্ট করুন, **Run** চাপুন। "Success" এলে হয়েছে।
3. যদি লেখা আসে `pg_net not available`: Supabase → **Database → Extensions** → `pg_net` খুঁজে চালু করুন, তারপর ফাইলটা আবার Run করুন।

## ২. Firebase প্রজেক্ট খোলা
1. ল্যাপটপে **console.firebase.google.com** খুলুন, traveladda2.0@gmail.com দিয়ে ঢুকুন।
2. **Create a project** → নাম দিন `Travel Adda` → Google Analytics **বন্ধ** রাখুন → **Create project**।

## ৩. অ্যান্ড্রয়েড অ্যাপ যোগ করা ও google-services.json
1. প্রজেক্টের প্রথম পাতায় অ্যান্ড্রয়েড চিহ্নে (রোবট) চাপুন।
2. **Android package name**-এ লিখুন ঠিক এভাবে: `app.traveladda.hajumrah`
3. **Register app** → **Download google-services.json**। বাকি ধাপগুলো (SDK যোগ করা) বাদ দিয়ে **Next → Continue to console**।
4. এই ফাইল GitHub-এ গোপন ঘরে রাখুন:
   - github.com/ADDAair/Travel-adda → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
   - Name: `GOOGLE_SERVICES_JSON`
   - Secret: google-services.json ফাইলটা Notepad-এ খুলে পুরো লেখা কপি করে পেস্ট করুন → **Add secret**

## ৪. Expo-কে পাঠানোর অনুমতি (FCM V1 key)
1. Firebase-এ বাঁ দিকের ⚙️ → **Project settings** → **Service accounts** ট্যাব → **Generate new private key** → **Generate key**। একটা .json ফাইল নামবে (গোপন!)।
2. **expo.dev**-এ traveladda অ্যাকাউন্টে ঢুকুন → প্রজেক্ট **travel-adda** → বাঁ দিকে **Credentials** → **Android** → `app.traveladda.hajumrah`।
3. **FCM V1 service account key** → **Add a service account key** → নামানো .json ফাইলটা আপলোড করুন → Save।
4. আপলোড হলে ল্যাপটপ থেকে ওই ফাইল মুছে ফেলুন (Recycle Bin থেকেও)।

## ৫. নতুন APK
আমাকে "পুশ সেটআপ হয়েছে" লিখুন। আমি নতুন APK বানাব (এবার Firebase সহ), তারপর:
1. নতুন APK ইনস্টল করুন, অ্যাপ খুলুন।
2. হোমে **"🔔 জরুরি খবর ফোনে পান" → চালু করুন** চাপুন, ফোন অনুমতি চাইলে **Allow** দিন।
3. অ্যাপ বন্ধ করুন। অন্য ফোন/ল্যাপটপ থেকে অ্যাডমিন হিসেবে **অ্যাডমিন → নোটিফিকেশন → একজন** দিয়ে নিজের আইডিতে একটা নোটিশ পাঠান।
4. ফোনে নোটিফিকেশন এলে কাজ শেষ। চাপলে অ্যাপের 🔔 পাতা খুলবে।

## যেভাবে কাজ করে (নিরাপত্তা)
- কোনো নোটিশ (চুক্তি, টাকা, দল, অ্যাডমিনের নোটিশ) 🔔 বক্সে এলে একই সময়ে ফোনেও যায়।
- ব্যক্তিগত নোটিশে লক স্ক্রিনে শুধু শিরোনাম দেখায়, বিস্তারিত দেখতে অ্যাপ খুলতে হয়। সবার জন্য দেওয়া নোটিশে শিরোনাম ও ছোট লেখা দেখায়।
- লগআউট করলে ওই ফোনে আর সেই অ্যাকাউন্টের নোটিফিকেশন যায় না। একই ফোনে অন্য কেউ লগইন করলে ফোন নতুন অ্যাকাউন্টের হয়ে যায়।
- বন্ধ (suspended) অ্যাকাউন্টে নোটিফিকেশন যায় না। অ্যাপ মুছে ফেলা ফোন নিজে থেকেই তালিকা থেকে বাদ পড়ে।
- কেউ চাইলে 🔔 পাতা থেকে ফোনের নোটিফিকেশন বন্ধ করতে পারেন; 🔔 বক্স আগের মতোই চলে।
- ইন্টারনেট বা পাঠানোর ব্যবস্থায় সমস্যা হলেও আসল কাজ (চুক্তি, টাকা ইত্যাদি) কখনো আটকায় না।
