# এসএমএস কোড (OTP) চালু করার নিয়ম

এই কাজগুলো ল্যাপটপে একবার করতে হবে। কোনো গোপন চাবি (API key, পাসওয়ার্ড) কাউকে চ্যাটে বা মেসেজে পাঠাবেন না, শুধু Supabase-এর Secrets ঘরে লিখবেন।

## ১. এসএমএস কোম্পানির অ্যাকাউন্ট

যেকোনো একটি কোম্পানিতে অ্যাকাউন্ট খুলুন, কিছু টাকা রিচার্জ করুন:

| কোম্পানি | SMS_PROVIDER-এ লিখবেন |
|---|---|
| BulkSMSBD (bulksmsbd.net) | `bulksmsbd` |
| Alpha SMS / sms.net.bd | `alphasms` |
| SSL Wireless (sslwireless.com) | `sslwireless` |

কোম্পানির কাছ থেকে দুটো জিনিস নিন: **API key** (বা API token), আর **Sender ID** (যদি তারা দেয়)। কোম্পানির API-এর নিয়ম বদলে থাকলে আমাকে জানাবেন, আমি মিলিয়ে দেব।

## ২. সার্ভার ফাংশন বসানো (Supabase)

1. Supabase-এ ঢুকে বাঁ পাশে **Edge Functions** খুলুন, তারপর **Deploy a new function** → **Via Editor**।
2. নাম দিন ঠিক এভাবে: `phone-otp`
3. এডিটরের সব লেখা মুছে `supabase/functions/phone-otp/index.ts` ফাইলের পুরো লেখা পেস্ট করুন। তারপর **Deploy** চাপুন।
4. ফাংশনের **Details / Settings**-এ গিয়ে **Enforce JWT verification** (Verify JWT) **বন্ধ** করুন। কারণ: "পাসওয়ার্ড ভুলে গেছেন" লগইনের আগে ব্যবহার হয়। লগইন লাগে এমন কাজে ফাংশন নিজেই লগইন যাচাই করে।

## ৩. গোপন তথ্য (Secrets)

**Edge Functions → Secrets** (বা Project Settings → Edge Functions)-এ এগুলো যোগ করুন:

| নাম | কী লিখবেন |
|---|---|
| `SMS_PROVIDER` | ওপরের টেবিল থেকে (যেমন `bulksmsbd`) |
| `SMS_API_KEY` | কোম্পানির API key |
| `SMS_SENDER_ID` | কোম্পানির Sender ID (না থাকলে বাদ দিন) |
| `OTP_DAILY_CAP` | দিনে সর্বোচ্চ কত এসএমএস (যেমন `300`)। এতে ভুল বা অপব্যবহারে ব্যালান্স শেষ হবে না |

## ৪. ডেটাবেস

`travel-adda-002-to-009.sql` পুরোটা SQL Editor-এ চালান (আগে চালানো থাকলেও আবার চালানো নিরাপদ)।

## ৫. পরীক্ষা ও চালু করা

1. অ্যাপে **আমার তথ্য → মোবাইল নম্বর যাচাই করুন** → কোড আসে কি না দেখুন, কোড লিখে যাচাই করুন।
2. লগআউট করে **পাসওয়ার্ড ভুলে গেছেন?** দিয়ে একবার নতুন পাসওয়ার্ড দিয়ে দেখুন।
3. সব ঠিক থাকলে **অ্যাডমিন → হেল্পলাইন → এসএমএস কোডে নম্বর যাচাই → বাধ্যতামূলক চালু করুন**। এরপর লিডারের আমন্ত্রণ শুধু যাচাই করা নম্বরে যাবে।

## নিরাপত্তা যা আগে থেকেই আছে

- কোড ৫ মিনিট কাজ করে, ৫ বার ভুল দিলে বাতিল হয়।
- একই নম্বরে মিনিটে ১টি, ঘণ্টায় ৩টির বেশি কোড যায় না; একই ইন্টারনেট ঠিকানা থেকে ঘণ্টায় ১০টির বেশি নয়।
- যে নম্বরে অ্যাকাউন্ট নেই, সেখানে এসএমএস যায় না, কিন্তু উত্তর একই দেখায়, তাই কেউ জানতে পারে না কে অ্যাপ ব্যবহার করেন।
- কোড সার্ভারে সরাসরি রাখা হয় না, শুধু গোপন রূপ (HMAC হ্যাশ)।
