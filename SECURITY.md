# Security / নিরাপত্তা

Found a security problem? Please write privately to **traveladda.z@gmail.com** (do not open a public issue).

- Never test on real users' accounts or data, and never try to read, change or delete data that is not yours.
- Do not run load tests or send SMS/notifications through the app.
- Give us reasonable time to fix the problem before telling anyone else.
